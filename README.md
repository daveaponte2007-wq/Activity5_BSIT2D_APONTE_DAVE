# Laboratory Activity: Stacks and Queues (Array vs. Linked List)

An educational implementation demonstrating linear structural operations using both sequential array allocations and linked structures.

## File Registry
* structures.py: Contains the implementations for Node, ArrayStack, LinkedStack, ArrayQueue, and LinkedQueue.
* main.py: Main driver application handling validation rules, circular array tests, CLI user menus, and application logic.
* analysis.md: Written technical responses analyzing linked list head modifications and array recycling mechanisms.
